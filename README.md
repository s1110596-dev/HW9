## 三、個人回答

### 問題一：測試一中，整理後的桌遊串列有 4 筆資料，為什麼桌遊費用應以 3 人計算？直接把字串拆成 list，和再轉成 set，各自保留了什麼、失去了什麼？

- **為什麼以 3 人計算**：整理後的桌遊串列為 `['amy', 'ben', 'amy', 'cora']`，其中 `'amy'` 出現了兩次，代表同一位參加者重複報名了桌遊體驗。根據活動規則，同一人在同一場活動中重複報名只算一位參加者、也只收一次費用，因此實際去重後只有 `amy`、`ben`、`cora` 共 3 人，費用為 $3 \times 120 = 360$ 元。
- **`list` 與 `set` 的差異**：
  - **直接拆成 `list`**：**保留了**所有原始報名紀錄（包含重複報名的次數）以及原本報名的先後順序；**失去了**資料的唯一性（無法直接得知實際有多少位不重複的參加者）。
  - **再轉成 `set`**：**保留了**所有不重複的參加者名單（自動去重，方便進行交集、聯集等集合運算）；**失去了**原本報名的先後順序，以及每個人重複報名了幾次的次數紀錄。

### 問題二：測試三中，兩場活動只有 3 位不同的人，為什麼是 6 人次、總應收仍是 600 元？請用集合關係與算式說明。

- **集合關係說明**：在測試三中，桌遊集合 $A = \{\text{'amy'}, \text{'ben'}, \text{'cora'}\}$，電影集合 $B = \{\text{'amy'}, \text{'ben'}, \text{'cora'}\}$。兩場活動的參加者完全相同，因此兩者的聯集 $A \cup B$ 與交集 $A \cap B$ 都是 $\{\text{'amy'}, \text{'ben'}, \text{'cora'}\}$，代表「總不重複人數」為 $|A \cup B| = 3$ 人（這 3 個人每個人都同時報名了兩場活動）。
- **算式說明**：
  - **報名人次**：計算方式為兩場各自去重後的人數相加，即 $|A| + |B| = 3 + 3 = 6$ 人次。
  - **總應收金額**：兩場活動分開計費，桌遊應收為 $|A| \times 120 = 3 \times 120 = 360$ 元，電影應收為 $|B| \times 80 = 3 \times 80 = 240$ 元，兩者相加得總應收 $360 + 240 = 600$ 元。
